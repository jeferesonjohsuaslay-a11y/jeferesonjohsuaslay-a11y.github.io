HTML & CSS

HTML (Hypertext Markup Language)

HTML adalah bahasa markup standar untuk membuat halaman web. HTML digunakan untuk menyusun konten dan struktur halaman web, termasuk teks, gambar, tautan, dan elemen lainnya.

CSS (Cascading Style Sheets)

CSS adalah bahasa yang digunakan untuk mengatur tampilan dan tata letak halaman web. CSS memungkinkan pengembang web untuk memisahkan konten dari presentasi, sehingga memudahkan pengelolaan desain dan konsistensi visual di seluruh situs web.

Dengan kombinasi HTML dan CSS, pengembang dapat membuat halaman web yang menarik, responsif, dan mudah dinavigasi.
